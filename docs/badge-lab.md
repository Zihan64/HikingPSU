# 徽章开发测试面板（Badge Lab）

这是一个独立的本地开发入口，用模拟定位、测试账号和内存数据库，复用正式的签到、评分和徽章业务流程。无需真实 GPS、Auth0 登录或 MongoDB 连接。

## 启动与停止

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-badge-lab.ps1
```

打开 <http://127.0.0.1:5176/dev/badge-lab.html>。后端仅监听 `127.0.0.1:8010`，前端仅监听 `127.0.0.1:5176`。日志和本任务进程记录保存在忽略的 `.tools/` 目录。启动脚本不修改 `.env`、`.env.local` 或系统环境变量。如果端口被占用，脚本会报错，不会停止其他程序。

需要已有 `backend/.venv` 和安装好的 `frontend/node_modules`；Node 优先使用项目 `.tools` 下的便携版本，否则使用 PATH 中的 Node。

停止：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-badge-lab.ps1
```

停止脚本只操作进程记录中属于当前项目、命令行与本测试环境匹配的进程。

## 快速测试一次真实徽章流程

1. 默认打开 Mount Nittany – Mike Lynch Overlook，测试账号是 **Badge Lab Tester**。
2. 面板选择“入口附近 · 精度 15 m”；点击网页中的 **Start hike · check in**。
3. 此时 **Finish & rate** 应不可用。面板点击“快进到可完成时间”，同时推进测试服务器时钟和页面时钟，不修改系统时间。
4. 点击网页中的 **Finish & rate**，填写三项评分并提交。
5. 成功对话框会显示新铜牌徽章，评分和徒步日志也会写入内存测试库。面板的“完成 / 徽章”计数会刷新。
6. 点击“查看徽章墙”查看正式 Profile 页面里的徽章和进度。
7. 点击“重置测试成就与时间”可清空测试签到、评分、日志和徽章，并恢复入口定位与真实时间。

面板可收起；在手机窄屏上，先设置场景，再收起面板操作网页即可。选择另一条路线后，点击“打开这条路线”；单纯切换定位不会强行跳走正在填写的表单。

## 场景

| 场景 / 操作 | 预期结果 |
| --- | --- |
| 入口附近、15 m 精度 | 正常签到 |
| 远离入口 | 被真实后端的 200 m 范围规则拒绝 |
| 精度不足、250 m | 被真实的定位精度／回退逻辑拒绝；该场景加速返回失败，无需等满 45 秒 |
| 拒绝权限／定位不可用／超时 | 显示相应失败，恢复入口场景后可重试 |
| 快进到可完成时间 | 仍按 `max(15 分钟, 预计时间 × 40%)` 计算；只推进测试时钟 |
| +1 分钟 | 检查接近完成时间的显示 |
| +1 天 | 测试跨日计数、重复徒步；每日 2 次完成限制仍保留 |
| +25 小时 | 检查签到过期，过期签到不能发徽章 |
| 重复完成同一路线 5 次 | 获得重复徒步特别徽章；需按每日限制跨日 |
| 完成一个公园全部路线 | 获得公园银牌；Other nearby trails 不计公园徽章 |
| 完成 10 / 30 条不同路线 | 检查里程碑徽章；不能通过手动添加徒步日志直接获得 |

## 隔离方式

- `backend/app/main.py` 不导入模拟器，也没有 `/__lab/*` 路由。
- 后端必须通过独立的 `dev.badge_lab:create_app` 工厂启动，并同时设置 `HIKINGPSU_BADGE_LAB=1`、`HIKINGPSU_ENV=development`；检测到 Render/AWS 托管环境会拒绝启动。
- 后端始终注入新建的 `mongomock.MongoClient`，使用固定内存库 `hikingpsu_badge_lab`。即使机器上有真实的 `MONGODB_URI`，也不会使用。关闭服务即丢弃数据。
- 正式身份校验不会放宽。只有独立测试应用覆盖依赖，固定为测试用户，并要求启动时生成的随机会话令牌。该令牌不能登录正式应用，不写入浏览器存储。
- 测试服务拒绝跨站来源和非本地主机；前端通过同源代理访问，不开启开放 CORS。真实 Auth0 账户删除在此应用中禁用，重置只清空固定的内存库。
- 独立 Vite 配置固定代理到测试后端，覆盖本次开发进程的 API/Auth0 公共设置，忽略 `.env.local` 中的正式 API 地址。没有真实 Auth0 登录、真实 GPS 或真实成就写入。
- `frontend/dev/badge-lab.jsx` 只供开发入口使用；普通生产入口不导入它。独立 Vite 配置拒绝 build，普通 `npm run build` 不包含测试页面或模拟器代码。
- 前端虚拟时钟和地理位置替换只影响这个开发标签页，不修改浏览器全局设置、其他标签页或操作系统时间。热更新时会清理替换和定位监听。

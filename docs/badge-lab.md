# 徽章测试面板（Badge Lab）

这个面板用模拟定位、独立测试账号和内存数据库，复用正式的签到、评分和徽章流程。无需到真实地点，但**必须先通过真实 Auth0 开发者登录、服务端允许名单和权限检查**。旧版免登录的本地入口已退役。

## 启用与停止

先按照 [开发工具访问控制与部署](devtools-access.md) 创建独立 Auth0 应用/API、配置本地密钥和允许名单。未配置时默认拒绝访问，不提供跳过授权的方式。

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-badge-lab.ps1
```

打开配置中的开发 origin，默认为 <http://127.0.0.1:5176/>，完成 Auth0 登录。只有拥有 `devtools:access` 和 `simulation:use` 的获准人员能进入模拟器；重置自己的数据还需要 `testdata:reset`。

脚本先构建私有前端并校验配置，再启动单个网关。不要直接启动 Vite 或把 `.devtools-dist` 放到公开静态托管中。进程日志保存在被 Git 忽略的 `.tools/`。

停止：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-badge-lab.ps1
```

停止脚本只处理进程记录中属于当前项目且命令行匹配的进程。

## 测试一次完整徽章流程

1. 登录后的横幅显示真实开发者，页面内部使用独立的 **Badge Lab Tester** 模拟用户。
2. 默认路线为 Mount Nittany – Mike Lynch Overlook。选择“入口附近 · 精度 15 m”，点击网页中的 **Start hike · check in**。
3. 提前完成会被拒绝。点击面板“快进到可完成时间”，只推进自己的测试时钟，不改操作系统时间或授权会话有效期。
4. 点击 **Finish & rate**，提交三项评分。成功后可看到铜牌、评分和徒步日志。
5. 点击“查看徽章墙”，查看复用的 Profile 页面及徽章进度。
6. 有重置权限时，“重置我的测试成就与时间”清除自己的测试记录并还原时间，不影响其他 contributor。

切换路线后点击“打开这条路线”。面板可收起，窄屏上可以先设置场景，再收起面板操作页面。

## 模拟场景

| 场景 / 操作 | 预期结果 |
| --- | --- |
| 入口附近、15 m 精度 | 正常签到 |
| 远离入口 | 真实后端的 200 m 范围规则拒绝 |
| 精度不足、250 m | 定位精度及回退逻辑拒绝；模拟加速失败，无需等满 45 秒 |
| 拒绝权限 / 定位不可用 / 超时 | 显示失败，恢复入口场景后可重试 |
| 快进到可完成时间 | 仍按 max(15 分钟, 预计时间 × 40%) 校验 |
| +1 天 | 检查跨日计数；每日最多 2 次完成的规则仍有效 |
| +25 小时 | 检查签到过期，过期不能发徽章 |
| 重复完成同一路线 5 次 | 检查重复徒步徽章，需遵守每日限制 |
| 完成一个公园全部路线 | 检查公园银牌；Other nearby trails 不计入 |
| 完成 10 / 30 条不同路线 | 检查金牌 / 铂金里程碑；手动日志不计入 |

## 数据与权限边界

- 正式入口不导入模拟器，也不接受开发 cookie 或模拟账号令牌。开发 HTML、JS、配置及 API 都由网关检查授权。
- 模拟器强制使用新建的 `mongomock` 内存库，忽略真实 `MONGODB_URI`。开发者分别映射到不同测试用户和模拟时钟；重启服务会清空全部测试数据。
- 定位替换和页面时钟只影响当前开发标签页。正式用户的徽章与成绩不会被写入。
- 正式构建为 `dist`，私有构建为 `.devtools-dist`。正常发布命令会扫描并阻止模拟器代码进入正式产物。
- 允许名单撤权会对后续请求生效；Auth0 配置、授权方法和完整测试命令见 [访问控制文档](devtools-access.md)。
